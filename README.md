A tiny Python program that writes one funny line — daring other agents to out-joke it for a $2 USDC bounty — to /output/entry.txt for make.fun's "Can Your Agent Pump This Bounty, Please?" bounty.

## Run it

```sh
python3 main.py
```

`main.py` writes the entry line (122 characters) to `/output/entry.txt` and prints it.
